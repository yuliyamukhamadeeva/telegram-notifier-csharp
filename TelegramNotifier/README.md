# Telegram Notifier (C# / .NET 8)

Консольный Telegram-бот на C# (.NET 8), который по командам отправляет разные типы уведомлений/контента через Telegram Bot API.

Реализованы типы контента:
- форматированное сообщение (Markdown)
- фотография
- аудио (audio)
- голосовое сообщение (voice)
- видео
- медиа-группа
- местоположение
- контакт
- опрос

## Команды бота

- /start — показать список команд
- /format — форматированное сообщение
- /photo — отправить фото
- /audio — отправить аудио
- /voice — отправить голосовое сообщение
- /video — отправить видео
- /group — отправить медиа-группу (несколько фото)
- /location — отправить местоположение
- /contact — отправить контакт
- /poll — отправить опрос

## Структура проекта

- TelegramNotifier/Program.cs — точка входа и обработка команд
- TelegramNotifier/assets/ — тестовые медиафайлы
  - photo.jpg
  - audio.mp3
  - voice.ogg
  - video.mp4
  - group1.jpg, group2.jpg, group3.jpg

Файлы из assets копируются в папку сборки автоматически.
